# Awesome GEO · AI 搜索监测与优化

> **GEO（Generative Engine Optimization，生成式引擎优化）** 关注的是：让品牌在 AI 问答与生成式检索中被准确提及、被优先引用。
>
> 传统 SEO 优化的是**一串排序的链接**；GEO 优化的是**一段被合成的答案**——模型决定检索什么、引用什么、给谁署名。衡量口径也因此而变：不只是排名位次，还有引用份额、提及语气与答案准确度。

本仓库收录围绕这一主题的观察笔记、选型指南与可复用方法。
